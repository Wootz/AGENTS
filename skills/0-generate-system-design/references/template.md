# System design specification template

The document is written in Traditional Chinese (正體中文). Keep the arc42 chapter numbers fixed, even for chapters marked 不適用, so readers familiar with arc42 can navigate it.

Bracketed text is guidance for the writer; replace it. Tags after a heading:

- *(推導)* — derived: write from the code and config.
- *(紀錄)* — recorded: write only from a cited source, or as a `TODO:`.

Cite a recorded item's source inline in parentheses, e.g. `（來源：ADR-0003）`, `（來源：使用者確認，2026-11-09）`, `（來源：docs/specs/訂單管理/訂單建立.md）`.
